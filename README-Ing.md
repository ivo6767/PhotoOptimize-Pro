# PhotoOptimizer Pro

PhotoOptimizer v1.0.0 is a native application for macOS Silicon (M1 and later), designed for batch image management, optimization, and downscaling, created to simplify the preparation of photographic files for the web and online platforms.

## 🚀 What It Does and What It Is For

The application allows you to quickly process entire folders or multiple image selections, automating the conversion, long-edge resizing, and compression workflow while ensuring the ideal balance between file size and visual quality for digital publishing.

## 📥 Input Files

PhotoOptimizer Pro supports the most common image formats used in photographic and digital workflows:

* TIFF
* JPEG
* PNG
* HEIC

## 📤 Output Files

* Optimized and compressed JPEGs, converted to the standard color space (sRGB), ready for web archiving or online sharing.
* Optimized and compressed WebPs, converted to the standard color space (sRGB), ready for web archiving or online sharing.

## 🎛️ Main Options

* **Web Option:** Optimizes and resizes the image by standardizing the long edge (e.g., 1920 px) for optimal display on web browsers and websites.
* **Juza Option:** Automatically applies the specific resizing and formatting parameters required for uploading and sharing within the JuzaPhoto community. Allows you to choose the long-edge length in pixels.

## ⚙️ Adjustable Settings

Within the application interface, you can customize:

* **Long Edge Length in Pixels:** Set the target length of the long edge while maintaining the original aspect ratio.
* **Sharpening Radius:** Determines the radius for the sharpening filter in pixels.
* **Sharpening Intensity:** Adjusts the strength of the sharpening filter.
* **Tonal Density:** Adjusts tonal density.
* **Resolution and Long-Edge Pixels:** For proportional resizing.
* **JPEG File Quality:** Choose the compression level for JPEG files.
* **WebP File Quality:** Choose the compression level for WebP files.
* **Before and After Preview:** View the before-and-after results in real time to fine-tune both sharpening and tonal density.
* **Source Folder:** Select the folder and its subfolders containing the files to be processed. Automatically excludes unsupported files from the list.
* **Destination Folder:** Choose where to save the processed files.

## ⚠️ WARNING:

During processing, files are loaded into RAM, so make sure the size of your TIFF files is smaller than your available RAM. Do not load layered TIFF files, as the process may become very slow and, in some cases, freeze, requiring you to force quit the application.
