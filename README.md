# PhotoOptimizer Pro

**PhotoOptimizer v.1.0.0** 
è un'applicazione nativa per macOS Silicon da M1 in su, progettata per la gestione, l'ottimizzazione e il ridimensionamento (downscale) di immagini in batch, pensata per semplificare la preparazione dei file fotografici destinati al web e alle piattaforme online.

## 🚀 Cosa fa e a cosa serve
L'applicazione permette di elaborare intere cartelle o selezioni multiple di immagini in modo rapido, automatizzando il processo di conversione, ridimensionamento del lato lungo e compressione, garantendo il perfetto bilanciamento tra peso del file e resa visiva per la pubblicazione digitale.

## 📥 File in Ingresso (Input)
PhotoOptimizer Pro supporta i formati di immagine più diffusi nel flusso di lavoro fotografico e digitale:
- **TIFF**
- **JPEG**
- **PNG**
- **HEIC**

## 📤 File in Uscita (Output)
- **JPEG** ottimizzati e compressi, convertiti nello spazio colore standard (sRGB), pronti per l'archiviazione web o la condivisione online.
-**WebP** ottimizzati e compressi, convertiti nello spazio colore standard (sRGB), pronti per l'archiviazione web o la condivisione online.

## 🎛️ Le Opzioni Principali
- **Opzione Web:** Ottimizza e ridimensiona l'immagine standardizzando il lato lungo (es. 1920 px) per una visualizzazione perfetta sui browser e sui siti internet.
- **Opzione Juza:** Applica automaticamente i parametri di ridimensionamento e formattazione specifici richiesti per il caricamento e la condivisione all'interno della community di JuzaPhoto. Possibile scegliere la lunghezza in Pixel del lato lungo.

## ⚙️ Cosa si può regolare
All'interno dell'interfaccia dell'applicazione è possibile personalizzare:
-**Lunghezza in Pixel del lato lungo** si può impostare la lunghezza del lato lungo e mantiene la proporzione originale.
-**Raggio Nitidezza** determina il raggio per il filtro nitidezza in Pixel.
-**Intensitò Nitidezza** regola l'intensità del filtro nitidezza.
-**Densità Tonale** regola la densità tonale.
- **Risoluzione e Pixel del lato lungo** per il ridimensionamento proporzionale.
-**Qualità del file JPEG** si può scegliere la compressione dei file JPEG.
-**Qualità del file WebP** si può scegliere la compressione dei file WebP.
-**Possibilità di vedere prima e dopo** si può vedere in tempo reale il risultato del prima e del dopo per poter decidere sia la nitidezza che la Densità Tonale.
-**Cartella di Origine dei File** per scegliere la cartella e le sue sottocartelle per prendere i file da processare. Esclude automaticamente dalla lista i file non conformi.
- **Cartella di destinazione** per salvare i file elaborati.

# ⚠️ ATTENZIONE:
Durante il processo il file viene caricato nella memoria RAM quindi si deve fare attenzione al peso dei file TIFF che deve essere inferiore alla quantità della vostra RAM a disposizione. Non caricate file TIFF con all'interno i livelli. Il processo potrebbe diventare molto lungo e in alcuni casi bloccarsi e si deve uscire dall'Applicazione.
